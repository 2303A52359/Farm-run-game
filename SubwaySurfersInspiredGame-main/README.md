# ❄️ Farm Run – Snow Theme

## 📌 Project Overview

**Farm Run – Snow Theme** is a 3D game developed using Unity. The project features a farm-themed gaming environment redesigned with a beautiful winter atmosphere.

The original farm environment has been transformed into a snowy landscape, creating a unique winter gaming experience.

This project is developed as part of an academic Game Design project.

## 🎮 Project Details

- **Project Name:** Farm Run – Snow Theme
- **Game Engine:** Unity
- **Unity Version:** Unity 6.6 (6000.6.0f1)
- **Game Type:** 3D Game
- **Theme:** Snow / Winter Wonderland
- **Platform:** PC / Windows

## 🚀 How to Run the Project

1. Install Unity Hub.
2. Install the compatible Unity Editor version.
3. Clone or download this repository.
4. Open Unity Hub.
5. Select **Add Project**.
6. Choose the downloaded Farm Run project folder.
7. Open the project in Unity.
8. Open the main game scene.
9. Click the **Play** button to start the game.

## 🎯 Project Objective

The objective of this project is to develop a 3D game using Unity and explore game design concepts by transforming a farm-themed environment into a winter-themed gaming experience.
