# Subway Surfers – Winter Theme

This is your original Unity project with a Winter Theme setup tool added. The existing player, animations, movement, obstacles, coins, scoring and gameplay scripts are kept.

## Open in Unity
1. Extract this ZIP file.
2. Open **Unity Hub**.
3. Select **Add > Add project from disk**.
4. Select the extracted `SubwaySurfersInspiredGame-main` folder (the folder containing `Assets`, `Packages`, and `ProjectSettings`).
5. Open it with **Unity 6.2 (6000.2.10f1)**, matching the project's original editor version.

## Apply the Winter Theme
1. Wait for Unity to finish importing the project.
2. In Unity, open the top menu **Winter Theme**.
3. Click **Apply to Main Game + Locker Menu**.
4. Wait for the scenes to save.
5. Open `Assets/Scenes/mainGameScene.unity` and press **Play**.

The setup adds cool blue winter lighting, pale blue atmospheric fog, and a falling-snow particle effect to the main game scene. It also applies the winter lighting/fog to the locker menu.

## Important
- Make a backup before editing if you have made your own changes.
- The first time you apply the theme, Unity creates `Assets/Materials/WinterSnow.mat`.
- This is a Unity project ZIP, not a standalone Windows game build. Open it through Unity Hub.
- If Unity reports a missing package or import error, let the import finish first and check **Window > Package Manager**.
